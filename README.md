# WalkScape Optimizer

A toolkit for optimizing your [WalkScape](https://walkscape.app/) gameplay — find the best gear for traveling, activities, and crafting, plan multi-stop routes, and analyze drop rates and crafting efficiency.

It comes in two forms:

1. **Web app** — a local browser UI (gear optimizer, crafting tree, stats report, route planner, calculators, and more). Run it with Docker.
2. **CLI toolkit** — standalone Python scripts you configure and run from the terminal.

## Option 1 — Web App (Docker)

The web app is the easiest way to use everything through a browser.

```bash
cd ui
cp docker-compose-example.yml docker-compose.yml   # then edit if needed
docker compose up --build
```

Then open **http://localhost:8000** in your browser and import your character.

- Full setup notes: [`ui/DOCKER_GETTING_STARTED.md`](ui/DOCKER_GETTING_STARTED.md), [`ui/QUICK_START.md`](ui/QUICK_START.md), [`ui/INSTALLATION.md`](ui/INSTALLATION.md)
- The app reads pre-generated game data from `util/autogenerated/`; no external services are required to run it.

> **Security note:** the app has no built-in authentication and is intended to run **locally / on a trusted network only**. Do not expose it to the public internet without adding your own protections.

### Optional: Google Sheets community data

The app can sync community-contributed item definitions from a Google Sheet. This is optional and **off by default**. To enable it, set your own sheet in `ui/sheets_config.py` (the shipped values are placeholders — `YOUR_LIVE_SHEET_ID`, `YOUR_APPS_SCRIPT_DEPLOYMENT_ID`) and set `SHEETS_SYNC_ENABLED = True`. See [`ui/SHEETS_DEPLOYMENT.md`](ui/SHEETS_DEPLOYMENT.md).

## Option 2 — CLI Toolkit

### 1. Set up your character

Copy the example config and paste your character export:

```bash
cp my_config.example.py my_config.py
```

Then edit `my_config.py`:

```python
CHARACTER_EXPORT = """{"name":"YourName",...}"""
```

**Where to find it:** in-game, go to **Settings > Account > Export Character Data**.

### 2. (Optional) Add gearsets

For travel-route optimization, add gearset exports (**Equipment > Gear sets > Export Gearset**):

```python
GEARSETS = {'default': "H4sI...", 'Diving': "H4sI..."}
```

### 3. Run an optimizer

```bash
python3 optimize_activity_gearsets.py
```

### CLI tools

| Script | What it does |
|--------|--------------|
| `optimize_travel_gearsets.py` | Best gear for traveling between locations |
| `optimize_activity_gearsets.py` | Best gear for fishing, foraging, mining, etc. |
| `optimize_craft_gearsets.py` | Best gear for crafting (incl. quality outcomes) |
| `travel_locations_optimizer.py` | Shortest route to visit multiple locations |
| `activity_drop_rates.py` | Expected steps per item drop for an activity |
| `gear_item_comparison.py` | Test whether a new item improves a gearset |
| `gearset_stats.py` | Detailed per-item stat breakdown for a gearset |
| `compare_two_items.py` | Compare two items side by side |
| `craft_compare.py` | Analyze how crafting bonuses combine |

Each script has configuration constants near the top (activity, recipe, sorting priorities, etc.) — open the file and edit them to your goal.

## Understanding the Stats

- **WE (Work Efficiency)** — reduces distance / steps (higher is better)
- **DA (Double Action)** — chance to skip paying steps / bonus action (higher is better)
- **DR (Double Rewards)** — chance for bonus items (higher is better)
- **NMC (No Materials Consumed)** / **QO (Quality Outcome)** — crafting bonuses
- Items can have **region-specific** stats; the optimizer applies the correct values automatically.

## Updating Game Data

When WalkScape adds new items or locations, regenerate the data from the wiki:

```bash
pip install -r requirements.txt   # installs beautifulsoup4 (only needed for scraping)
python3 util/scrapers/rescrape_all.py
```

The optimizers themselves run on the Python standard library only.
